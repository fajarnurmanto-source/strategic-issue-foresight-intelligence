## 1. Purpose

S0.6C qualifies the currently audited source universe for the SIFI
Stage0 foundation.

It determines:

- which sources are currently known and rights-reviewed;
- which sources may be used only for research/discovery;
- which sources are candidates for controlled production use;
- which information roles remain without lawful production coverage;
- where substitution capacity remains unresolved;
- whether a Minimal Viable Production Source Universe currently exists.

S0.6C does not force source sufficiency where evidence does not support it.

## 2. Universe Separation

SIFI maintains distinct source universes.

### U1 — DISCOVERY / RESEARCH UNIVERSE

Sources may contribute to lawful discovery, research, verification
triggers, or context within their applicable restrictions.

Z1 material may exist here.

### U2 — PRODUCTION EVIDENCE UNIVERSE

Only material admitted under the applicable production rights and
evidence-admission controls may support canonical production findings.

A source-level candidate Z2 state does not automatically admit every
Evidence Item into production.

### U3 — DERIVED OUTPUT UNIVERSE

Z3 SIFI outputs must retain sufficient lineage to their admissible
supporting evidence.

Z3 may not launder Z1 into production evidence.

## 6. Qualification vs Production Sufficiency

A source can be QUALIFIED AS RESEARCH-ONLY.

That does not mean the source is qualified for production evidence.

S0.6C therefore distinguishes:

- SOURCE_STATE_QUALIFIED;
- PRODUCTION_ROLE_COVERED;
- PRODUCTION_MVU_SUFFICIENT.

These states must never be collapsed.

## 7. Information Coverage vs Rights Coverage

INFORMATION COVERAGE ≠ RIGHTS COVERAGE.

A source may provide high informational value while remaining unusable for
production evidence.

A source may also have permissive rights while contributing insufficient
information value.

Both dimensions must remain visible.

## 8. Source Roles

The current audited cohort provides candidate roles including:

- official statistical / empirical baseline;
- national structured/open-data discovery;
- weather and environmental information;
- local regulation;
- local official government reporting;
- local structured/open data.

These are current candidate information roles.

Their inclusion does not imply that all are sufficient, necessary, or
independently production-qualified.

## 9. Source Diversity

Source count is not a sufficient diversity measure.

SIFI must distinguish at minimum:

- source family;
- informational origin;
- evidence role;
- geographic pack;
- rights state;
- independence / syndication relationship.

Six sources do not automatically imply six independent evidentiary origins.

## 10. Substitution

A source must not be declared safely substitutable merely because another
source covers a similar topic.

Substitution requires evidence about:

- information role;
- geography;
- temporal coverage;
- evidence quality;
- independence;
- rights;
- access reliability;
- material loss caused by replacement.

Current formal substitution capacity for the audited cohort is:

NOT_YET_ESTABLISHED

until a source-specific substitute is demonstrated.

## 11. Source Loss

Loss, suspension, rights regression, or access failure of a source must
trigger:

- ingestion stop where required;
- production-evidence admission stop where required;
- coverage-gap assessment;
- substitution review;
- affected Issue / output lineage review where material.

Source loss must not silently appear as issue disappearance.

## 12. Geographic Portability

Kota Yogyakarta remains the first pilot CoverageProfile.

The source universe must not create Yogyakarta-specific core product logic.

A source may be important for one profile and irrelevant or replaceable for
another.

Rights state does not mutate merely because CoverageProfile changes.

## 13. Rights Point-in-Time Rule

Source qualification is point-in-time.

Every production-relevant source decision must retain:

- verification state;
- rights state;
- access route;
- commercial-use state;
- candidate zone;
- production eligibility;
- review date;
- evidence locator where applicable.

Later rights changes do not rewrite earlier rights states.

## 14. Revalidation

The current rights snapshot is not a perpetual licence.

Before operational use, relevant source rights must be revalidated according
to applicable governance and source-specific review requirements.

## 15. No Automatic Promotion

The following are prohibited:

- Z1 → Z2 because a source is useful;
- Z1 → Z2 because the source is official;
- Z1 → Z2 because content is public;
- Z1 → Z2 because an analyst approves it;
- source-level Z2 candidate → automatic Evidence Item Z2;
- derived Z3 output → laundering of Z1 evidence.

## 16. No Invented Sufficiency Threshold

S0.6C does not invent:

- minimum source count;
- minimum media count;
- arbitrary geographic quotas;
- arbitrary diversity scores;
- arbitrary recall targets.

Where empirical sufficiency cannot yet be established:

NOT_QUANTIFIABLE_FROM_CURRENT_EVIDENCE.

## 17. Product Claim Boundary

Existence of S0.6C supports only the claim:

"SIFI has a rights-qualified current source-universe classification and an
explicit record of unresolved production-coverage gaps."

It does not support claims that:

- the production source universe is sufficient;
- the source universe achieves adequate issue recall;
- all relevant issues can be detected;
- source loss can already be substituted;
- the current cohort supports commercial production;
- SIFI has operational source acquisition.
