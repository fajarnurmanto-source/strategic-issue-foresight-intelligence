implemented path does not automatically promote attention into downstream
event/impact/strategic conclusions.

an impact-severity or strategic-priority engine.

be asserted merely by assigning an enum.

context and obtain the Z2 admission through RightsPolicyEvaluator before the
evidence is used as production-eligible support inside the fixture.

proof of real-world production evidence performance.

### CB12

canonical control requires a public reference with explicit rights review.

### CB21

CB21 is materializable because point-in-time behavior exists across current
evidence/publication persistence, Issue persistence, review history and
temporal-rights surfaces.

information.

A result is invalid if later evidence or corrections leak into the historical
assessment.

### CB24

CB24 remains blocked by reference materialization rather than missing
runtime capability.

Before its executor is created, S1.6D must create an explicit canonical
predecessor/hash and contract-assertion manifest.

The executor must evaluate that manifest and the relevant regression controls;
it must not reduce CB24 to merely "the unit tests passed."
