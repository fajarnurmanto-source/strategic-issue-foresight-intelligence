## Rule

A canonical case is MATERIALIZABLE_NOW only when a bounded executor can
exercise:

scenario input
→ current implementation behavior
→ observable output
→ Expected / Forbidden adjudication
→ resolvable execution evidence.

Representational capacity alone is insufficient.

The existence of a similar unit/component test is also insufficient.
